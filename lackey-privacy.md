LeagueLackey is a Discord bot that operates on the Dominion Discord server to support the running and moderation of the Dominion League. It automatically collects frequent snapshots of data on all members of the Dominion Discord server. The following data is collected for all server members:
- Discord username
- Discord account ID ("snowflake")
- Global Discord display name
- Local Dominion server nickname
- Discord roles (for example, "New League Player") that the user has on the Dominion server.

LeagueLackey never collects any other user information from Discord, such as membership in other Discord servers, or the content of any messages posted other than posts in which it is tagged.

Data collected by LeagueLackey is stored in a secure spreadsheet accessible only to members of the League Moderator team and is encrypted at rest. No data is ever shared with any third parties or used for any purpose other than the running and moderation of the Dominion League.

Data from each snapshot is generally stored for 5 minutes and then deleted and replaced by the next snapshot. At the end of each League season, a final snapshot is retained for a longer period when data for that season ceases to be updated. This final snapshot is deleted within 30 days of collection.

By signing up for the Dominion League, you agree to collection and storage of your Discord data in the manner described above.

To request deletion of your Discord user account data from all League records and/or opt out of future data collection, please contact the League Moderator team via the Dominion League Hotline or email dominionleaguemoderator@gmail.com. You may make this request if you are (or have previously been) a member of the Dominion Discord server, regardless of whether you participate in the Dominion League or not. Please note that you will not be able to participate in the League if LeagueLackey does not have permission to collect your data.
